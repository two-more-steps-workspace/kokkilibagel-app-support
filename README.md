## 앱 빌드별 기능 안내

아래 숫자는 앱의 빌드 번호입니다.

- **기존 빌드 3:** 공식 온라인몰 화면 외에 앱의 헤더·탭, 저장한 상품·공유·이용 안내 기능이 있습니다.
- **빌드 4 이후:** 기존 모바일 온라인몰 화면을 그대로 사용하며, 별도의 앱 헤더·탭·저장·공유·이용 안내 화면은 제공하지 않습니다. 온라인몰 자체의 메뉴와 기능은 이용할 수 있습니다.
- **빌드 7의 알림 연결:** 기존 로그인과 휴대폰의 시스템 알림 권한을 사용합니다. 전용 서버가 안 읽은 알림 개수의 증가를 감지하면 일반 안내 푸시를 전달하는 방식이며, 전체 기기·실제 새 알림 수신 검증은 진행 중입니다. 자세한 정보 처리는 아래 ‘앱 알림 연결’을 확인해 주세요.

## 앱 개인정보 처리 안내

### 온라인몰에서 처리하는 정보와 목적

앱은 공식 온라인몰의 회원·상품·주문 서비스를 이용합니다. 이용자가 입력하거나 사용하는 기능에 따라 다음 정보가 처리됩니다.

- 회원가입·계정 관리: 이름, 이메일 및 회원 식별 정보, 비밀번호, 연락처, 성별, 생년월일, 주소, 프로필 사진 등 입력한 회원정보. 회원 확인·인증, 계정 관리와 서비스 부정 이용 방지에 이용합니다.
- 상품 주문·배송·취소·고객 문의: 주문·구매 내역과 처리 상태, 수령인 이름·연락처·주소, 이용자가 작성한 문의·후기와 첨부 콘텐츠. 주문·배송·결제 정산, 고객 요청 처리에 이용합니다.
- 방문·이용 분석: 방문 페이지와 이용·검색 정보, 유입 경로, 방문 시각, 쿠키 식별자와 브라우저·기기 환경 정보. 온라인몰 통계, 서비스 개선과 광고 유입·전환 분석에 이용합니다. 현재 온라인몰에는 아임웹 통계·CRM 및 네이버 로그 분석 연동이 있습니다.

회원·거래·권리 행사에 관한 상세한 수집 항목과 고지는 공식 온라인몰의 가입·주문 화면 및 [개인정보처리방침](https://kokkilibagel.com/?mode=privacy)을 함께 확인해 주세요. 카드 등의 결제정보를 결제 제공자 화면에 입력하는 경우 해당 제공자의 안내도 적용됩니다. 기존 빌드 3의 상품 저장 기능은 카드정보를 읽거나 저장하지 않습니다.

### 처리 위탁과 외부 서비스

공식 처리방침에는 아임웹(호스팅·서비스·마케팅 및 부가 서비스), 토스페이먼트 PG(결제·에스크로), CJ대한통운(배송), 이커머스 고객센터(상담), 인포빕·루나소프트(문자·카카오 알림톡/친구톡 발송 대행)가 기재돼 있습니다. 온라인몰은 네이버 로그 분석을 통해 방문·유입·전환 정보를 분석합니다. 각 서비스에 필요한 정보가 해당 기능과 목적을 위해 처리됩니다.

카카오 로그인이나 온라인몰 자체 공유 기능, 기존 빌드 3의 앱 상품 공유 등 외부 서비스를 이용자가 선택하면 해당 서비스의 안내와 개인정보처리방침도 확인할 수 있습니다. 앱에는 별도의 광고 SDK나 자체 회원·주문 서버를 추가하지 않았습니다. 아래 앱 알림 연결은 기존 온라인몰과 분리된 전용 서버에서 처리합니다.

### 앱 알림 연결

앱은 로그인한 회원의 기존 알림을 휴대폰에 알려주기 위해 다음 정보를 처리합니다. 상품 조회·로그인·쇼핑은 기존 온라인몰 화면을 그대로 사용하며, 휴대폰 알림 표시는 시스템 알림 권한과 기기 설정에 따릅니다.

- **최소 로그인 세션 식별값:** 공식몰 WebView의 `IMWEBVSSID` 쿠키 하나를 전용 서버로 전송합니다. 기존 회원 확인과 안 읽은 알림 개수 조회에 사용합니다. 로그인 비밀번호, 다른 자동 로그인 쿠키, 광고·추적 쿠키를 이 알림 서버로 복사하지 않습니다.
- **회원·연결 식별값:** 원본 온라인몰에서 확인한 회원코드, 회원코드의 키 기반 HMAC 파생 식별값, 앱 설치 식별값과 로그인 연결 세대를 처리합니다. 회원과 기기를 연결하고 다른 회원의 알림이 섞이지 않도록 확인하는 데 사용합니다. 파생 식별값도 회원 연결에 쓰이며 익명 정보라고 보장하지 않습니다.
- **푸시 토큰과 연결 자격증명:** 전용 서버에는 해당 앱 설치의 Expo 푸시 토큰을 보관합니다. 기기의 설치 자격증명은 보안 저장소에 보관하며 서버에는 설치 비밀값의 검증용 해시를 둡니다. Expo와 기기 알림 공급자도 전달에 필요한 기기 토큰을 처리합니다.
- **알림 처리 상태:** 안 읽은 개수의 비교 기준, 증가 순번, relay 관찰 시각, 발송·수락·전달 확인 및 재시도 상태를 처리합니다. 운영 감지는 알림 목록의 원문 제목·본문 대신 안 읽은 개수만 조회합니다.

정보는 기존 온라인몰·재고 예약 서비스와 분리된 **코끼리베이글 전용 AWS 서버**에서 처리합니다. 전송에는 HTTPS를 사용하며 로그인 세션 식별값, 원본 회원코드, Expo 푸시 토큰과 발송 대기 내용은 AES-GCM으로 암호화해 보관합니다. 암호화된 정보를 서버가 알림 기능을 위해 사용할 수 있으므로 개인정보 수집이 없다는 뜻은 아닙니다.

알림 전달에는 **Expo 푸시 서비스**, Android의 **Google Firebase Cloud Messaging(FCM)**, iOS의 **Apple Push Notification service(APNs)**를 이용합니다. 기기 토큰과 일반 안내 문구, 공식몰 링크, 알림·연결 식별값이 전달 과정에서 처리됩니다. 이 전용 relay는 해당 정보를 회원 알림 연결·전달과 연결 보안에 사용하며 광고나 광고 추적 용도로 사용하지 않습니다. 기존 온라인몰의 통계·마케팅 처리는 위 온라인몰 안내가 별도로 적용됩니다.

첫 개수 조회는 과거 기준선으로만 기록하고 알림을 보내지 않습니다. 이후 안 읽은 개수가 증가하면 **‘새 알림이 도착했습니다 / 앱에서 알림을 확인해 주세요.’**라는 일반 안내를 보내며, 알림을 누르면 공식몰을 엽니다. 개별 알림 원문·주문 상세를 푸시에 복제하지 않습니다. 여러 새 알림은 한 안내로 묶일 수 있고, 조회 사이 읽음·새 알림이 함께 발생해 개수가 늘지 않으면 감지되지 않을 수 있습니다. 실시간·모든 항목 전달을 보장하지 않습니다.

알림 연결 정보는 연결이 유지되는 동안 기능 제공을 위해 보관합니다. 앱에서 로그아웃해 연결 해제 요청이 서버에서 처리되거나, 서버가 세션 만료·다른 회원으로의 변경을 확인하면 해당 연결에 보관한 세션·회원코드·토큰·대기 데이터를 삭제합니다. 기기가 오프라인이면 해제 전달이 지연될 수 있으며 앱은 해제 요청을 다시 전송합니다. 취소한 연결이 지연 요청으로 되살아나는 것을 막기 위해 취소된 설치 식별값과 취소 시각은 남길 수 있습니다. 연결 정보의 삭제 요청도 아래 방법으로 처리합니다. 이미 전달 서비스가 수락했거나 휴대폰 알림함에 표시한 알림은 회수되지 않을 수 있습니다.

시스템 알림 권한을 끄는 것과 전용 서버의 연결 정보를 삭제하는 것은 서로 다른 처리입니다. **온라인몰 계정은 유지하면서 앱 알림 연결 정보만 삭제하려는 경우에도 위 고객센터 이메일로 요청할 수 있습니다.** 요청 제목에 ‘코끼리베이글 앱 알림 연결 정보 삭제’를 적고 가입 이메일과 요청 범위를 알려 주세요. 세션 쿠키, 설치 비밀값, 푸시 토큰이나 비밀번호를 보내지 마세요. 운영 담당자가 필요한 본인 확인과 범위를 확인해 처리 결과를 안내합니다.

### 기존 빌드 3의 기기 저장 상품 목록

기존 빌드 3의 ‘저장한 상품’은 **상품명, 공개 상품 링크, 저장 시각**을 해당 기기에 보관합니다. 이 목록을 별도 서버나 온라인몰 회원 계정에 전송하는 기능은 없습니다. 빌드 4 이후에는 앱의 상품 저장·목록 기능이 없습니다.

- 빌드 3에서는 앱의 **저장한 상품 → 저장 취소**에서 각 상품을 지울 수 있습니다.
- 빌드 4로 업데이트해 저장 화면이 없어져도 기존 기기 데이터가 자동 삭제된다고 보장하지 않습니다. 남아 있는 기기 보관 데이터는 기기의 앱 데이터 삭제 또는 앱 제거로 정리할 수 있습니다.
- 기기 목록 정리와 온라인몰 회원탈퇴는 서로 다른 처리입니다. 계정과 연결된 개인정보의 삭제는 위 고객센터로 요청해 주세요.
